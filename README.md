# dialogue-robot
本项目使用SenceVioce作为ASR模型，CAM++作为声纹识别，edgeTTS作为TTS模型，语言模型可使用deepseek-r1-7B模型，但作为对话机器推理太啰嗦，最终换为Qwen-7B-Instruct
通过RAG管理将每次对话存储为向量，并通过相似度加以关联，获得相关对话生成增强提示词，作为上下文信息
为提高唤醒词成功率，将唤醒词转为拼音比对，唤醒词可更换，目前为你好小荣
回答过程中持续检查语音，检测新语音自动打断播放
每次对话都进行声纹识别，匹配得分较低讲无法使用，因此这个对话机器人只属于你自己
目前问题在于启动前需等待加载RAG对话，对话中大约10s左右做出回答
